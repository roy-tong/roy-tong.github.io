FLAGSHIP PROJECT · v0.2.2

AgentMeasure

Open measurement infrastructure for the Agent Capability Economy.

Reach → Choice → Use → Utility → Value

As software consumers shift from humans to agents, installs, seats, and page views no longer describe software value well enough. AgentMeasure measures how agents discover, select, invoke, and derive value from software capabilities before metering, marketplaces, and Capability as a Service are built on top. Current state: Standard Draft 0.4.4, a conformance vector suite (with the first community-contributed fixture Urusilla-001), the first public evidence case, the open-source Lab experiment engine (78 tests), and the first preregistered A/B on a real agent.
