LIBRARY NOTES · 2026.08.31

Public source ledger

What does the cited source explain, and keep that it does not prove anything. The author's project, manufacturer's document and research paper are marked separately.

This page only lists public sources. The original local information does not enter the site; the author's analysis that can be made public has been reorganized into knowledge units. Relevant old articles are linked separately on each knowledge page, and the original release time is kept.

The link and the scope of application were reviewed on August 31, 2026. The manufacturer's document is used to confirm the capability description, not as an independent performance test; the project draft is not used as an industry consensus.

  • AgentMeasure Core Specification

    Author's project specification

    Attempt, operation and evidence semantics; drafts are not commonly adopted by the industry.

  • AgentMeasure · Langfuse demo traces

    Public presentation data case

    The adaptation and review of public demo trace does not represent the production flow or causal return.

  • AgentMeasure Lab

    Author's project experimental tools

    Experimental engine and synthetic example; synthetic uplift is not extraposed to the real Agent upgrade.

  • SURE · User Demand Research

    Author's project and method

    Research contract, evidence grading, CLI and MCP; structural inspection is not equal to the establishment of requirements.

  • iRead

    Author's project

    Source discovery, event de-weighting and reporting workflow; do not claim that the long-term use value has been verified.

  • Bilibili Transcript Pipeline

    Author's project

    Transcription tools and processing processes; the tool license does not cover third-party video content.

  • LM Studio · Offline Operation

    Technical documents of manufacturers

    The offline ability of downloaded models, document processing and local services; does not cover the networking behavior of external tools.

  • Ollama · Context length

    Project technical documents

    The relationship between context settings and memory occupation is not used to compare the task performance of different hardware.

  • NVIDIA · Jetson Product Lifecycle

    Manufacturer's supply description

    The life cycle difference between the module and the development kit; it is not the service commitment of any device.

  • OpenTimelineIO documentation

    Open source project documents

    Editing information exchange: fragments, time, tracks, tags, metadata; no embedded audio and video.

  • Runway · Creating with Gen-4 Image References

    The manufacturer uses documents

    Reference diagram and role/scene consistency workflow; manufacturer's ability description, not independent reliability test.

  • C2PA · Content Credentials Explainer

    Standard organization description

    Content source and anti-tampering mechanism; the source certificate does not judge the authenticity of the content, nor does it automatically grant copyright.

  • OpenVLA

    Research projects and papers

    Training and evaluation of visual language action models; only support the tasks and experimental conditions disclosed in the paper.

  • DROID

    Research data set

    Cross-scene real machine operation data and collection infrastructure; scale cannot replace specific task adaptation.

  • iRobot · Roomba s Series Care Frequency Chart

    Manufacturer's maintenance instructions

    Maintenance items and frequency of a specific series; used to illustrate the existence of maintenance labor, and do not infer the failure rate of the whole industry.

  • PrusaSlicer · Print settings

    Technical documents of manufacturers

    Materials, printing and equipment parameters affect the production process; they are not ranked as equipment advantages and disadvantages.

  • World Labs · A Functional Taxonomy of World Models

    The classification proposal of the research team

    The output function distinguishes renderer, simulator and planner; it is not a unified definition of the industry, which does not mean that the ability has been integrated.
