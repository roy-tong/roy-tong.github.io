AgentMeasure

Open measurement infrastructure for the Agent Capability Economy.

Reach → Choice → Use → Utility → Value

当软件的消费者从人变成 Agent，传统安装量、席位和页面访问不足以描述软件价值。AgentMeasure 先把 Agent 对软件能力的发现、选择、调用与价值测清楚，再为未来 Metering、Marketplace 与 Capability as a Service 提供计量基础。当前状态：规范 Draft 0.4.4、一致性向量套件（含首个社区贡献 fixture Urusilla-001）、首个公开证据案例、Lab 开源实验引擎（78 tests）、真实 Agent 上的首个预注册 A/B。
