FLAGSHIP PROJECT

AgentMeasure

Open measurement infrastructure for the Agent Capability Economy.

Reach → Choice → Use → Utility → Value

当软件的消费者从人变成 Agent，传统安装量、席位和页面访问不足以描述软件价值。AgentMeasure 尝试先把 Agent 对软件能力的发现、选择、调用与价值测清楚，再为未来 Metering、Marketplace 与 Capability as a Service 提供计量基础。
