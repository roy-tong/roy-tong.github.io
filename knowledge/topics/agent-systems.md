**覆盖**：软件如何接住交给 Agent 的长期任务——需要什么上下文、能力怎样被调用、执行事实如何保存、使用与价值如何区分。

**读法**：先读《Agent 运行时》，看一个 Agent 怎样持有任务状态；再进入能力分发与能力经济；最后用计量方法把"被使用"和"创造价值"分开。

**检验**：AgentMeasure 与 iRead 提供可检查的实现与边界。
