已开源持续迭代

iRead

让 Agent 持续跟踪一个或多个领域：先审核信源和代表作，再生成日报、周报和月报。

  • 区分原创证据、二手转述与重复信息
  • 数据与报告默认保留在本机
  • 保留人工审核，不把自动生成当作最终判断

SURE 行业研究 Skill

用“用户角色 × 场景/触发 × 任务 × 替代方案 × 摩擦 × 后果 × 证据等级”组织研究，内置六类采样框、E0–E5 证据等级和质量审计流程。

Agent 输入 / 输出：决策问题与证据数据 → 研究契约、证据账本、质量审计与机会卡。
